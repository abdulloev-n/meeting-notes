# Meeting Notes — Interactive UX Concept

This GitHub Pages branch contains a standalone, interactive browser prototype of Meeting Notes. It is separate from the Windows/Tauri source code on `main`.

Visit: https://abdulloev-n.github.io/meeting-notes/

## Features demonstrated
Home, Meetings, Search, Calendar, Settings, collections, transcript search, word-level audio seeking, bookmarks, demo translation, summary modes, source-grounded sample Ask AI, import drag/drop and local media playback, Markdown / DOCX / PDF export.

## Important
Recording, device indicators, transcription and AI processing are simulated in this UI concept. Imported files are played locally in the current tab and are never uploaded. Meeting state and collections are stored in your browser localStorage.

Visual direction follows shadcn/ui design tokens and compact Windows desktop composition. This is a zero-dependency prototype for UX review, not the production React/Tauri implementation.
